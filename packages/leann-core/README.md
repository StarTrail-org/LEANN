# leann-core

Core APIs, CLI (`leann`), embedding pipeline, and backend plugin registry for [LEANN](https://github.com/StarTrail-org/LEANN) — a lightweight local vector/RAG stack.

For installation, backends (HNSW, IVF, DiskANN), and full documentation, see the [main repository README](https://github.com/StarTrail-org/LEANN/blob/main/README.md).
